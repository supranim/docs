## What are Starter Kits?
Starter kits are pre-built project templates that provide a solid foundation for building web applications with Supranim. They include **essential features**, **configurations**, and best practices to help you get started **quickly and efficiently**.

## Homemade Starter Kit v0.1.0
Or first starter kit, designed to provide a solid foundation for building web applications with **Supranim**. It includes essential features such as **user authentication**, **session management**, and a **simple dashboard** to get you started quickly. **Homemade Kit** is perfect for developers who want to jump right into building their applications without worrying about the initial setup.

Check it on GitHub: [https://github.com/supranim/homemade-app](https://github.com/supranim/cartier-app)


![Cartier Starter Kit](https://github.com/supranim/app/raw/main/.github/starter-screenshot.png)

## How to Use Starter Kits
The most idiomatic way to use a starter kit is to use [Supra](/cli), the CLI tool for managing Supranim projects. With Supra, you can easily create a new project based on a starter kit with just a few commands.
